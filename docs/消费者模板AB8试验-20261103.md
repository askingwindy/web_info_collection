# 消费者模板 AB8 试验

用户授权当前工程两个模板族各四条，共八个新 Table2 候选，一半模板优先、一半原 ReAct，每条一次正式执行，所有正式保存均做同样本真实独立 AI QC。不补第九条，不启动其他生产或发布。唯一进度入口为 `verify_results/consumer-template-ab8-20261103-r01/进度.md`，实际清单与源码冻结以该目录证据为准。

## 工程代码

`webcollect.consumer_templates` 为可选会话适配器，普通消费者不导入它。Matcher 检查当前可信页面及目标适用性；Executor 直接调用原会话的 observe/act/finish 宿主实现，原 inspect 及 ReAct 随时可用；Verifier 绑定可见结果或正文引用，不授予 QC PASS。入口 `webcollect.consumer_template_experiment` 只接收显式冻结八条，复用原 scope、候选池、派发门禁、独占领取、账本、注册库与正式后加工/verified_saved。

计算器模板绑定本页可见数字字段、单位/选择、参数和唯一计算按钮，逐字段 set_value 后核对实际值，点击一次计算并核对新结果。未知量求解、日期、多义标签、缺单位/选择、控件或结果不明确时记录回退原因，交回原 ReAct，不重派旧动作。百科模板只适用于正文词条，不接受 Portal/Wikipedia 命名空间。只从原树main/article正文区域选标题及段落，排除nav/aside/header/footer；按本次目标在正文内向前定位，保存阅读位置及新显示正文；不把目录文字当作读到的正文，不往返凑步。

每次模板意向与结果有独立事件，汇总区分模板直跑、模板与 ReAct 混合、原 ReAct；零模板实际派发不算模板执行。实际动作仍按原子原件与效果重算。原范围结束政策、25 次 GLM HTTP 上限、UNKNOWN 保护和正式保存门禁继续生效。异常尾部不能变成目标完成。

## 规划采集 Agent

goal：两组保留原 requested_goal。明确目标不能可靠解释时均由原 ReAct 按原参数执行。原目标为空时共用 `trusted-first-frame-common-goal-2`：数字计算页选择可见字段对应的固定演示数值并保留当前单位/选择，结果条件为新可见的计算结果；词条依据首帧正文和章节建立定向阅读目标，结束条件为目标正文与章节边界。选目标规则不依赖分组，适用信息不足则双方都回原 ReAct 建目标；发生的真实 GLM 调用全部计量。

prompt：回退及原 ReAct 沿用冻结工程协议和提示，接收共同建立的工作目标、真实轨迹、阅读位置和最近工具结果。宿主模板不制造模型 response，不将提示或指纹命中算执行。

tools：模型可见的原四工具和参数不变。模板宿主调用相同工具实现；模型只有在原 ReAct 回合才获得原请求/HTTP/usage 记录。无模型模板回合记录零新增 HTTP，实际 HTTP 另从原账核对。

验收：新增定向离线检查及直接受影响会话/候选链检查；真实固定八条每条报告首访、正式尝试、原子派发、有效步、目标与末态、路由与回退、原保存收据、独立 QC、时间/等待、采集与 QC 分账 HTTP/token/UNKNOWN。八条始终保留为分母，失败和未决不换样。样本 AI 状态、人工审核、批次正式接纳、发布及客户验收分列。
