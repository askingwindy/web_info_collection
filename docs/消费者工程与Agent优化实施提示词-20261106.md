保留旧 V1 六步规则的历史含义，不只改 MINIMUM 常量。

套现有恢复入口。终点用最后可信原 after 帧，未知/失败尾部留在原件，不能跨越拼接。

走正式加工、capture audit、身份/去重、保存收据与原账回读，最多到 collected_pending_review。
