# 生产者首帧图片占屏“无需消费”规则

2026-11-04 后续V9有界100页实测已结束并停止，真实执行图片探针192次、NO_CONSUME正例0，仍不能验收正例筛除效果或宣称整体提速。实测补充单页失败隔离和检索冷却前置检查，未批量重标历史存量，未启动消费者或轨迹QC。[实测结果及归因](生产者V9新挖掘100页与性能归因-20261104.md)。

首次实现阶段，用户进一步确认生产者沿用消费者的首帧图片覆盖率规则，取消地图、图表、图片工具、正文、控件和图片说明等语义例外。规则更新为 `producer-first-frame-image-2`；新具名批次仍显式指定 `entry-tools-9`。该首次实现阶段仅工程与离线验证，没有恢复真实生产、批量标记真实存量、消费者轨迹或轨迹QC。

## 当前判断口径

|观察|处理|
|---|---|
|可信首帧中已加载、可见且无遮挡的IMG，矩形并集覆盖视口≥95%|记录 `NO_CONSUME / 无需消费`，不进入用途模型及后续消费|
|命中≥95%，但标题是地图/图表/图片工具，或有正文/控件/图片描述/明确目标|仍按同一规则排除，不做额外业务规划|
|覆盖率不足95%，或地图/图表使用canvas、SVG、CSS背景且没有足量可见IMG|此规则不作排除，继续原流程；不按类目整体拉黑|
|图片未加载、离屏、遮挡、缺少可信几何、截图前后变化或访问未决|UNKNOWN/HELD或原访问失败；不能推定已命中，不重发原UNKNOWN|

生产者直接复用 `consumer_page_policy.full_image`，与消费者使用相同的95%阈值、视口裁剪及矩形并集算法。重复框不累加面积，离屏与不可见图片不计入。用途和可规划性不再是图片筛除条件，也不新增语义模型判断。

这是一条项目筛选取舍，可能舍弃本来有业务价值的图片页面。按用户本次选择接受这项取舍；不把该标记描述为用途错误或不可操作的独立审核结论。

## 工程与生效方式

- `image_screen.js` 只读取可见IMG几何，不再遍历整页正文、业务控件或图片说明。使用生产者匿名只读浏览器，不执行点击、输入、登录或下载。
- `page_consumption.py` 校验原job、visit、HTTP2xx、应用/入口/落地URI、DOM与PNG摘要、视口尺寸及截图前后稳定性。截图后仍等待1.2秒复核；消费者保留原首帧兜底，防止页面变化或其他来源遗漏。后续实测修复使HTTP不合格或已有持久失败账的探针异常只保留本页HELD，不中断其他页；无原账宿主故障及原件损坏仍抛错。
- 新V2标记覆盖 `entry_and_target`：领取、发布和跨批次链接准备共用原pool的checkpoint，命中后跳过开页、用途模型和后续消费。已在途、已保存的任务不撤回，原ID、正文、version、来源、状态、费用和历史收据不改写。
- 规范URI的原浏览器请求标识沿用，不因规则版本升级重发UNKNOWN。旧版成功观测在有完整证据时可由V2重新判定，不重新访问。旧版已经存在的标记和作用域原样保留，不覆盖或伪造新收据。
- 新批次显式用 `--model-protocol entry-tools-9`，冻结配置记下V2规则和范围。旧冻结9会话不能被静默改成V2，配置不符时应保留原版本处理；默认协议仍为7。
- 标记只针对已证实URL及落地别名，不扩大成整站禁用。业务查询参数和SPA路由独立；标记不自动过期，当前无自动解封流程。

仅查询已有状态，不访问网络：

```sh
PYTHONPATH=projects/code:projects/site-planner:projects/quality-inspector \
projects/code/.venv/bin/python -m site_planner.page_consumption \
  --pool <原pool> --uri <URL>
```

已有URL可由生产者单独取证：同一命令增加 `--probe --config <原producer_config> --ledger <原producer_db> --history-set <原manifest> --output <原工程证据目录下的新目录>`。首次会执行真实只读浏览器访问，要求原工程绑定及mode=real，本轮未执行。`--result <result.json>` 则复核已有原始证据，不重新访问。缺少可见证据的存量仍不凭印象批量标记。

## Agent优化与速度边界

**工程代码：**共用确定性几何函数及原库短事务，移除语义保护扫描，并在生产者用途调用及消费者领取前拦截。验收核对阈值边界、发布/领取跳过、跨批次复用和原账兼容。

**Agent goal：**生产者提前执行消费者既定的图片占屏淘汰标准，减少无效候选进入规划。**Prompt：**用途提示词和v6用途验收口径不变。**Tool宿主：**取得并核验可见几何后判定，不新增模型调用。**模型可见tool协议：**用途模型只看到剩余候选，排除原因和证据写入宿主生产收据。

这能减少命中页面在消费者侧的领取、浏览器开页和后续规划成本；现有消费者本就会在首帧阈值命中后、模型规划前放弃，因此新增收益主要是省掉领取和开页。生产者首次需要增加浏览器观察，缓存命中可复用；整体吞吐、费用及提速比例尚未实测，不能承诺固定增幅。
