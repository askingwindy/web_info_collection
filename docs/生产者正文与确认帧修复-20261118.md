## 当前实现

- `discovery_tools.py` 在成功 goto、确定 HTTP 失败分类之后，先于页面等待/观察/截图读取并保存 `response-body.bin`，保留原5秒和4MB限制。最终仍核对响应 URL、观察 URL 和当前页面 URL；明确 HTTP 失败仍直接走原失败出口。
- 同一页面最多确认两次。首次失败保留 JSON、PNG、DOM，沿用 `wait_ready` 最多1.2秒后再确认一次；不调用第二次 goto，不新建 GET 或模型请求。每次截图仍限10秒，完整 read 仍限60秒，截图异常不进入重确认。
- 两次确认都要求前后有效主区且签名相同。持续为空或变化仍失败，诊断区分 `main_region_empty` / `main_region_changed`。第二次使用独立文件名，成功结果绑定第二次图文与 DOM，并引用首次失败原件。
- `READINESS_SCRIPT` 的根区域、可见性、遍历上限和排除规则未改。重等可容纳短暂延迟，不能据此宣称三个历史页面已修复成功；activity 投影漏检仍待可复现 DOM 定位。以后确认失败会保留原响应体和 DOM，补齐定位原件。

模型决策协议、页面批大小、入口排序、字体截图超时和导航 UNKNOWN 处置均未修改；100个候选未启动消费者，两个旧 UNKNOWN 没有重发。
