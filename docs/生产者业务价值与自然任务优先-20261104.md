# 生产者业务价值与自然任务优先

本轮按用户要求调整生产者判断方向：用途保留为辅助信息，UNKNOWN不直接阻断消费；不为补齐分类重复开页或调用模型。选入重点是本页主营业务价值与自然任务方向。仅修改工程、Agent协议并做临时夹具离线验证，未恢复真实生产，不启动消费者或轨迹QC，不修改原工程、manifest、原账及历史失败/UNKNOWN。

新入口为显式 `--model-protocol entry-tools-11`，业务决策版本 `producer-business-task-1`。沿用原生产者CLI、原候选工程和账本参数，不能新建库或换绑定来运行；既有批次按原冻结协议恢复。默认入口仍为7，V10及其100页标签、收据和独立参考不重解释。

## 工程代码优化

原V10已经允许用途UNKNOWN入池，但整个业务/用途响应共用schema校验，用途字段或引用协议出错可能使业务选入一并失败。类型结构编号和长页前缀还扩大schema；实际用途阶段token没有明显下降。新模块为 `projects/site-planner/site_planner/producer_task_value.py`。

宿主先独立核对业务与任务核心字段：本页非泛化业务引文、`public_business`、明确任务提示及其本页引文。用途缺失、非法、引用不匹配或结构不足，只保留UNKNOWN及原因，不改变已经通过核心核验的选入结论。反过来，用途已知不能替代业务价值或任务证据。业务/任务核心不明仍待确认，不自动记为“无需消费”。

`task_value`采用supported、limited、unsupported、UNKNOWN。supported与limited都需要具体对象/自然活动提示及本页证据；limited在本生产小批排在supported之后。该排序不代表消费者已经支持优先级。短介绍可低优先保留，不为五步凑动作，也不预测实际步数。所有任务提示标明 `HINT_ONLY_NOT_EXECUTED`，消费者仍须依据真实首帧形成工作目标；提示不进入Table2的冻结requested_goal，entry正文仍是原四字段。

新协议只读已绑定的匿名观察文档，没有原文档时不补GET、不派发空材料模型。页面读取沿V10同次匿名GET复用：原响应、DOM、PNG分别保存，业务判断与发布绑定原job/visit。普通历史地址排除与发布均复用原收据；只有既有显式定向entry_recheck按其原授权处理，不为分类触发复核。

同一材料、URI、站点上下文和模型下，每页最多一次业务/任务判断。无论选入、拒绝、用途UNKNOWN还是已结算核心协议错误，均保存本轮原判定缓存；换小批不重新派发。已结算invalid_response只读原响应核对显式核心字段，保留原错误状态，不从reason补值；未结算请求仍按原账隔离，不重新命名派发。损坏的原证据继续报错，不能以新读覆盖。

图片覆盖≥95%的原NO_CONSUME规则、原失败/UNKNOWN保护与Table2主键/短事务独占领取不变。消费者、轨迹QC和生产库均未改动。

## 站点挖掘Agent优化：goal、prompt、tool

Goal是寻找与站点主营相关、能形成有意义自然活动的公开入口，不以用途分类完整率为生产目标。公开阅读、条目浏览与检索都可有任务价值；不强求表单，不强制每页可做五步。

Prompt要求对照实际内容和原站点主类，不能只信栏目名或URL。例如健康栏目下实际为风水黄历时，应记录mismatch而非因“有文章”选入；营销、隐私、登录帮助不能当主营库存。任务提示必须有具体对象与自然活动/预期信息，不能只有“浏览网页”。用途可省略或UNKNOWN，不要求补证、inspect、循环分类或声明可消费/已采集/审核通过。

模型可见tool为一次 `submit_supply_decisions`，按page_key返回业务、业务引文、task_value、task_hint、任务引文和理由；page_type与purpose_quote_ids为可选辅助字段。不再要求模型选择结构ID，不向模型发送大量结构事实。材料仍有界并披露省略；引文使用页内短q编号，宿主在对应page_key下精确核对成员，不在多个schema字段反复列出长编号枚举。字符数和schema收敛只是工程措施，本轮没有实际模型usage，不能宣称已经实测节省token或提高消费成功率。

查询规划也改为业务与自然活动方向，不为补用途分类发起检索。沿用现有模型作业种类以保持原账隔离/计量契约，具体语义由payload的 `producer-business-task-1` 版本和method说明。

## 验收与边界

定向用例覆盖：UNKNOWN仍入池并可由临时领取API领取；用途缺字段/错误引用/结构不足不挡有效核心；已知用途不能放行业务错配或无自然任务；有限阅读低优先；法律页不得借任务提示进入；同页换小批零模型重派；原invalid_response只读复用；真实传输超时夹具的原UNKNOWN跨小批不重发；缺原文档不补GET；正式生产者入池/历史排除/重入不增加GET；四字段正文和requested_goal不变。

最终离线收据及源码绑定见 [本轮检查入口](../verify_results/producer-task-value-20261104-r01/完成说明.md)。首轮失败夹具和源码稳定失败均保留；没有消费者执行、真实网页/模型验证、独立业务验收、人工审核或发布。本轮不会回写V10那8个用途UNKNOWN，也不自动将暂缓页面设为永久无需消费。后续真实运行需要明确有界范围，继续原工程原账。
