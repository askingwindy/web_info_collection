# 消费者规划采集 Agent 实施计划与五候选实测

2026-11-02。本轮先验证改版能否在不同网页上取得有可见依据的连续操作，再依据五条原账决定下一轮优化。实施交给独立的 Codex 会话 `gpt-6.1-sol / high`。网页采集仍用工程现有 GLM 配置，一个候选由一个 Agent 在一个浏览器会话内执行。主会话负责批末日志复核。

## 实现范围

| 工作 | 模型看到的变化 | 宿主验收 |
| --- | --- | --- |
| 首帧与定向观察 | 保留同步原图。控件摘要区分文字／组别线索、已证明的标签、当前可执行性和下一取证方式。需要补探针的共性可合并表达。已显示和可按需找回的材料有明确边界。 | 优先复用同步树、`compact_observation` 和 `inspect(search/control/html)`。用历史百分比、OSGeo、公交及速度计算器首帧回放。无探针、遮挡、歧义、旧观察不得因新增线索变为可派发。 |
| 选题与进度 | 保留冻结的 `requested_goal`。仅有入口时基于可信观察定工作目标与可见结束条件，同等有用时优先自然多步。预计少于五步、有自然多步依据或暂未知可写在已有简短摘要中。每轮只选择一个原生工具。 | 有输入、执行中和已完成等状态分别核对。有效步数只按真实原子派发及其效果重算。已有两项定向观察或一次语义操作均不能直接折算为轨迹长度。 |
| 首轮集合事实 | 在有选择空间的首轮提供一份紧凑的当前工程快照，区分短流程占比与近重复涉及的唯一样本占比。目标已固定时保持原参数。 | 复用明确的有效集合、规则和汇总报告，绑定范围与来源。给分子、分母及统计状态。进行中的保存数另标口径。无适用快照、分母为零或相应判重未完成时，返回 `UNKNOWN` 及原因。不能挪用其他工程、历史对照包或五条名单充当正式总体。相近轨迹仅在已有可绑定证据时给线索。 |
| 动作和结束 | `act` 反馈突出与目标相关的实际变化。`finish` 可以用短引用表达本轮实际观察，保留已做阶段、可见事实和未完成项。 | 引用必须绑定该次模型请求的原观察和 attempt，历史／过期／异会话引用不能默认为最新。对外 Schema 或绑定含义变化时做版本兼容，原协议与原件按旧版本回读。核对自然完成与预算停止，避免把只发生聚焦写成已得到业务结果，保留合法连续片段。 |

维持 `observe / inspect / act / finish` 四工具。真实的标签页能力缺口、需独立规划顾问的案例在批后分类。本轮的五条使用同一执行策略，不据此宣称单、多 Agent 或占比提示的因果收益。

## 离线验证后才启动这五条

1. 先读 `AGENTS.md`、当前工程 scope 和来源、当前实现及 Git 状态，保留已有改动。主要模块为 `react_protocol.py`、`react_context.py`、`react_session.py`，必要时涉及直接调用方、`postprocess.py`。复用已有 Python、SQLite 和报告，按实际修改维护相关说明。
2. 在新验证目录使用 README 的选定离线验证入口，覆盖修改模块和直接调用链。至少对照有／无探针、摘要找回、冻结目标、当前／过期 finish 引用、真实结果与单纯聚焦、无集合及已知集合、旧协议恢复。历史原件只读，真实请求与模拟检查分开。
3. 从当前 `candidate-project-20261101-r01` 的生产者 Table2 选择 **5 个不同的已发布且当前可派发的候选**。先核对原项目 manifest、候选版本、来源／GET 收据、原领取／处置、原账 UNKNOWN 和在途情况。尽量分散到 5 个应用及不同交互形态，在可用池和现行入口约束下记录选择理由。可参考既有三站清单，资格以本次只读回查为准。正式首访前冻结名单、原始目标／NULL、生产批次、执行顺序、源码／Prompt／工具指纹、模型配置非敏感身份和输出路径。跨生产批次时分别绑定原 scope，合计分母仍为 5。
4. 仅恢复这份名单的规划采集，依原消费者入口逐候选独占执行。入口候选的工作目标留给真实首帧，实跑不预填答案。每个采集 attempt 最多 25 次真实 GLM 请求，传输超时只沿现有原账及同一调用策略处理。已派发动作效果未决时只能对账。同一候选的失败如实保留，按既有隔离规则处理后继续名单中的其他合格项。正式保存按官方流程回读。不得以补选第六条、重置、改账、拼接、全局恢复或静默切换实现版本取得更好数字。
5. 先完成整份名单，再统一评估。本次授权是五候选采集，保存输出按既有流程交接待审。统计真实已有 QC 结果，程序校验、样本级独立 AI、包级、人工、发布和客户验收分列。独立 QC 新模型审查不作为实跑启动前置或本次已完成项。

## 新会话交回的原件

选用全新本地证据根，优先 `verify_results/consumer-agent-five-20261102-r01/`，若已占用则递增编号。提供实施摘要、离线结果、冻结名单、批前／批后原账摘要、**恰好五行**的机器可读结果及中文汇总。每行绑定候选 ID/版本、URL、原生产批、工作目标、访问/attempt/样本身份、到达阶段、工具顺序、模型 HTTP／有 usage 数／已知 token、实际派发／有效步、停止首因、可见终态、正式保存状态，以及首帧、决策、轨迹、终态或失败、保存收据的绝对路径。未进入某阶段写明原因，未知用量单列。已保存样本核对原 PNG／树／动作与正式收据摘要。首轮集合事实与版本快照一并保留。不得输出凭据或提交样本、SQLite、请求原件与验证目录。
