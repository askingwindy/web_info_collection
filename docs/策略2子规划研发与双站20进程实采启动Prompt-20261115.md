## 3 必须有的关键日志

| 事件 | 关键内容 |
| --- | --- |
| strategy_selected | 实际使用的采集策略、站点、入口URL |
| strategy_rejected | 请求的策略、入口、拒绝原因；策略1请求必须在浏览器/模型/采集动作前拒绝，不能记录为已选择策略2 |
| template_selected | 所选模板；来源为confirmed_site/page_match/generic_fallback；简短匹配理由；必要的可见结构依据；已确认模板不适用的原因 |
| first_plan_result | 固定或自主目标、最终目标简述、计划步数、接受或拒绝及具体原因 |
| plan_revised | 实际偏差、剩余缺项和修订后步数；不要把每张新截图都记成重规划 |
| completion_result | 原目标是否完成、实际有效动作数、未满足事项或结束原因 |
| sample_saved | 正式保存结果、实际模板、sample_id；保存失败明确记录，不能凭模型complete打印成功 |
| template_site_progress | 本站本模板不同成功页面数、是否达到3页、是否新增登记及三个sample_id |
| site_target_reached | 本轮该站实际保存数、停止新领取时间、在途数量 |
| worker_finished | 退出原因、已处理与未执行数、保存数、失败及UNKNOWN |

model-calls.jsonl继续记录实际HTTP、耗时及token；能取得模板名时一并携带，缺失用量保留null。不要重复输出完整DOM、图片base64、凭据或大段提示词。
