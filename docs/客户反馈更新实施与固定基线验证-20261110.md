## 可选标注接口

Python：`annotation_corrections.correct_annotations(source, output, source_index=..., sample_ids=..., fields=..., apply=False)`。默认只输出可改性报告，显式 `apply=True` 才生成新的 `samples` 修订候选。原 `postprocess.revise` 不用于该低成本接口，因为它会重新派生完成状态。

```sh
PYTHONPATH=projects/code:projects/site-planner:projects/quality-inspector projects/code/.venv/bin/python -m webcollect correct-annotations   --source delivery/202611100331   --source-index verify_results/consumer-193-readonly-analysis-20261110-r01/samples.jsonl   --output verify_results/NEW-ANNOTATION-REVISION   --field hotkey --field expected_result --field next_step_rationale --apply
```

输出 `corrections.json` 记录样本/步骤/字段、原值/新值、规则、依据文件及哈希、未决原因；`execution-evidence.json` 可传给 `build_client_package(..., execution_evidence=...)` 或 `package --execution-evidence`。只有显式选择修订目录作为 source 才导出该版本；导出核对实际参数，不自动改旧标注。仍须满足适用交付资格及独立 QC，不能将所有订正版直接视为有效集合。
