### 2. 通用阅读规划允许以下自然组合

以下三种是离线验收路径族示例，不是要求真实模型逐字照抄，也不是所有任务的固定模板。

**A1：老页面多段阅读，跨页继续阅读，再返回**

1. 老页面滚动到相关正文区域 A；
2. 老页面滚动到新的相关正文区域 B；
3. 点击相关链接并核验新文档；
4. 新页面滚动阅读与目标相关的正文；
5. 返回老页面并核验原页面身份。

**A2：老页面多段阅读，跨页核对后返回续读**

1. 老页面滚动到相关正文区域 A；
2. 老页面滚动到新的相关正文区域 B；
3. 点击相关链接并核验新文档；
4. 返回老页面并核验原页面身份；
5. 老页面继续滚动到新的相关正文区域 C。

**B：两次有独立目的的跨页查阅**

1. 老页面点击相关链接甲并核验新文档；
2. 返回老页面；
3. 老页面滚动到新的正文区域或相关链接乙；
4. 点击相关链接乙并核验新文档；
5. 返回老页面。

实现边界：

- Agent 根据冻结目标、当前观察、未完成 checks 和实际动作效果选择下一动作，不预先机械枚举排列组合。
- 每次 scroll 必须对应新的相关正文区域、目标字段或未完成阅读事项；`scrolled=true`、`found=true`、截图数量或像素变化量本身不等于有效步。
- 每次 click 必须有独立查阅目的，并核验实际新 URL、文档标题或正文及加载完成状态。第二次点击原则上选择另一个相关链接；若再次点击同一链接，必须有可核验的新阅读目的，不能机械重复同一内容。
- 每次 back 必须核验原 URL、标题、正文身份和连续轨迹，不因调用 `history.back` 或等待而自动计步。
- wait、observe、inspect、finish、加载等待和模型声明均计 0 个有效步。
- 固定 wwiki 目标不得改写成“日食与月食比较”，也不得强制模型必须跨页。搜索、打开条目和多段正文阅读自然达到 ≥5 步即可；跨页只在模型依据当前目标和页面证据自主认为相关时使用。
- `webcollect-direct-article-reading-1` 的专用约束继续保留：从已打开正文开始、禁止站内搜索、跨文档后下一业务动作必须是 back。A1 的“关联页继续滚动”只可用于允许该行为的通用协议，不得借此放宽 direct-article 旧协议。
- 真实基线若自然只有 1–4 步，仍按事实 `short_flow`，并且本轮 ≥5 步验收不通过；不得手工补一个动作、改写终态或伪称普通样本。
