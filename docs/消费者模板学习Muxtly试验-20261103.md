# Muxtly 成功轨迹模板学习与跨页复用

本轮授权最多三个当前工程 Table2 倒序新计算器，每条一次正式执行。只读种子为 AB8 `S000064_sample_000006`（法国个税、原 ReAct、样本独立 AI 五项 PASS、包级 FAIL）；不重审种子、不改变候选 URI 或原目标、不补候选、不发布。

证据与唯一进度入口为 `verify_results/consumer-template-learning-muxtly-20261103-r01/进度.md`。首次派发前冻结正式 NEW 发布时间及原入库顺序倒序扫描记录、排除依据、候选版本/原目标、第一方材料、库、源码、策略与定向验证报告。当前工程原 scope/manifest/原账沿用。

工程入口为 `webcollect.template_learning_experiment`，参数 `capture|independent-qc|audit --cohort <冻结清单> --directory <本轮目录>`；capture 还需 `--worker`。运行使用本轮冻结源码副本，凭据只由原 runtime 读取。普通消费者与 AB8 入口独立可用。

`TemplateLibrary.learn` 从正式保存的核验轨迹生成可执行程序，绑定原动作和结果证据；执行器实际读取该程序，拒用缺失、乱序、未知步骤。源实际是否提交后滚动会改变程序。参数角色从当前可信帧重新绑定，库不保存源税率、参数、URL 或答案作为执行常量。一个种子仅证明已示范原语；重复字段、按钮定位属于有界工程泛化，要靠本轮实测判断收益。

消费者 Agent 的原 goal/prompt/四工具协议保持，未命中/灰区/中途失配沿同一状态交回原 ReAct；模板宿主直接执行的动作不冒充模型调用。初始首帧无法读出选择值时只记录保留项并做一次原宿主定向观察，仍不明确就回退，不用隐藏 HTML 数值代替显示证据。所有实际动作走原同步 PNG/树、探针、派发前复查及效果门槛；提交后允许表单离屏，结果仍须绑定单次提交和同帧可见名称/数值。

每次正式保存后调用同一提炼入口形成草案；独立 QC 可异步绑定。只有源样本独立全帧五项 PASS 才可试用，跨页模板直接执行正式保存与同样本独立 PASS 后才标为同站已复验。静态匹配、真实命中、直接执行、部分回退、原 ReAct、保存和 AI PASS 单列。采集 HTTP/已知 usage/UNKNOWN、提炼及 QC 的时间和 token 分开，法国原 ReAct 187.7 秒、7 HTTP、140763 token、4 有效步作为带难度差异的历史参照，不据此作等难度因果推断。

本轮分段冻结的事实与限制：首次派发使用 `cohort.json` / `checkout`，前两条暴露候选默认接入另一条件计划协议的问题，原失败保留。在第二条 consume 已返回、无运行作业、第三条尚未领取的安全边界停止自己的驱动器后，`checkout-v2` / `cohort-tail-v3.json` 仅继续原第三条；局部清单保留 `original_order=3`。可选入口现在显式冻结 `session_wiring=template-original-four-tool-react-2`，在任务身份生成前选择原四工具协议，且拒绝带其他计划控制器的任务。普通入口默认不变。

开发源码后续的 learned-calculator-4 进一步拒绝把纯参数回显视为计算结果，已重新只读导入同一法国原件/QC到本工程 `consumer-templates-v4.sqlite3`，不重审。v4 的源正例和负例为离线验证，未参与先前 v3 的真实派发，不能追认 v3 结果或宣称已真实复验。各版本库和命中时快照均保留。

复用范围是当前 manifest/候选池绑定的可选消费者入口；并非普通消费者默认启用的全站模板。调用 `TemplateLibrary(path, manifest, pool)` 后，可用 `learn(pool, claim_id)` 从正式成功保存提炼草案，`qc_binding(...)` 与 `apply_qc(...)` 异步接入原独立结果；实际有界消费通过 `template_learning_experiment capture`，冻结清单还须绑定当前源码、原 scope、初始库与定向检查，并声明上述 `session_wiring`。本轮原始冻结清单用于原件核对，不作为再次派发授权。
