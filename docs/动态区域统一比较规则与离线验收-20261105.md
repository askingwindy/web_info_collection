用户 2026-11-05 再次重申的既有要求是本轮实现补齐的依据：公告、广告、动态图片可在其区域内变化，包括 main 内。目录、正文链接、广告及图片目标仍可点击。完整原 PNG/DOM、原失败、费用、编号、任务身份和旧冻结结论保留。此次仅做本地浏览器夹具、封存 HTML/CSS 派生重放与模拟模型/QC；没有新增真实网络、模型、采集或历史 AI 重审。

## 工程实现

共享实现为 `projects/code/webcollect/dynamic_regions.py` 与 `snapshot.js` 原生分类证据，版本 `webcollect-dynamic-regions-1` / `webcollect-dynamic-region-stability-1`。类别依据原生 id/class/role/可见结构、图像绘制及原生动画，不接受任意 data 字段或模型标注自授豁免。所有 IMG 表示图像内容允许变化，不声称每图都证明了动画。无可见文字的叶节点 CSS mask/background 图像单独取证；有正文的 hero/main 不因此丢掉正文。

普通可见后代绘制框合并进入区域边界，明确裁切可约束内部 transform/shadow/伪元素。原生空 CSS 伪元素图形使用 absolute px、margin、transform-origin、轴向非负矩阵、有限 keyframes 与无过冲 easing 的保守包络。未知外溢、旋转/倾斜或未证动画组合继续拒绝，不能按站点名称或坐标扩框。伪元素的宿主按钮/链接/标签/值留在语义投影中。

真实输入、原生 output、result/answer/total 等语义、calculation-output 等组合语义、控件关联结果、当前操作目标与明确引用/断言保护独立核验。空值非可见 submit/button 焦点库存不等于真实输入，但其身份/值/焦点仍保留。外层公告因真实业务字段不合格时，内部独立广告/图像仍单独评估。带色无关页脚被广告覆盖不自动否决整区；遮住当前目标或业务结果仍拒绝。

## Agent goal / prompt / tool

首轮、分支/replan 和原生 ReAct 都可见同一允许变化规则与紧凑区域目录。区域仍可读/可点击；模型须依据真实任务语义选择证据。公告轮换、GIF 换帧、脉冲图形本身不能替代用户目标、正文阅读或点击效果。原具体词条目标保持：目录同页锚点无需返回；跨词条下一业务动作返回；不站内搜索、不提供不支持的原生 find；引用不等于完成，显式完成仍覆盖首轮冻结问题与 checks。

QC 通过 `tool_result.return_value.goal_evidence.dynamic_region_evidence` 取得实际轨迹帧的类别、位置、原生依据和原件引用，同时取得首次目标/checks、操作和完成回答。分类证明不是 AI 质量 PASS。

## 未授予与边界

尚不支持任意未知绘制/多重非线性 transform 的通用像素因果判断。混合广告自身背景与未能独立界定的真实输入/结果交织时仍保守拒绝；其独立子广告/图像可分别处理。任意无语义标识、无原生关联的业务结果不能仅靠词法分类得到完整语义保证，实际目标/断言及独立 QC 仍必须验证。该机制不修改网页动画、DOM/CSS、原截图或原请求。

本地工程通过不增加真实采集产量：具体词条仍为 6 failed claims、4 formal attempts、7 请求（3 invalid_response / 4 succeeded）、70,513 tokens；保存/待审/实际 QC/合格/发布均为 0。R16 原 UNKNOWN/hold、Muxtly 四项内容通过为旧规则历史收据，差异 1 FAIL / 2 UNKNOWN / 19 未审均保留。
