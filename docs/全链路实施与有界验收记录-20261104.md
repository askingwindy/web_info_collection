## Agent 与宿主边界

消费者 Agent 仍由真实首帧截图、可见 DOM 和原目标提交 `submit_plan`，只有需要判断的分支才修订余下步骤；本轮没有把目标答案、业务操作脚本或站点特例写进执行器。模型可见协议沿用冻结 plan-8，新增宿主局部规则只决定已有动作能否安全派发。每会话最多 25 次真实 GLM 调用。精简反馈没有另作实测时，不声称 token 节省。

QC Agent 只裁决实际焦点样本及当前对照材料。宿主负责租约、发送期限、逐对保存、覆盖聚合和原账费用；传输修复不将未审对象视为通过。可信前缀按其客户自然目标及历史末帧审核，原任务目标是否完成另列。语义规则变化只使相关绑定失效，不自动重做旧样本审核。

挖掘 Agent 的 goal 是引用当次页面证据，找出有基本业务价值的公开入口；prompt 和工具只需给出页面编号及业务依据。宿主复用原 GET/DOM/截图，核验第一方实际落地 2xx、图片覆盖、身份去重和发布收据；不要求消费者任务或预测消费可执行性。旧 V11 提示与收据保持原义。
