## 最小实现接线

- `screenshot_plan.py`：规划规则、当前结果展示判定、在线与封存复核统一。
- `screenshot_session.py`：历史证据索引、输入事项自动核验、已验证证据增量合并、准确缺项反馈、真实完成事件时间。
- `screenshot_observation.py` / `screenshot_execution.py`：仅在上述投影、当前绑定和执行事实确需接线时修改；不放宽焦点、选区或身份校验。
- `postprocess.py` / `collect.py` / `annotation_corrections.py`：动作相关变化、可见输入值、客户叙述与终态生成一致；保存原计划及原始检查，避免内部字段进入客户文字。
- 完成共享事实：`completed_at` 是真实完成事件时间；`goal_evidence.final_visible_evidence` 保存经核验的当前展示依据。具体字段与封存重算同步，禁止只增一个 prompt 字段而不改宿主。
- 进展判定只依赖稳定业务状态、已核实事实与新内容，不把新的 observation 编号当作业务变化；对模型投影隐藏内部 selector/identity，私有精确身份仍用于执行与验证。
- 新首轮路线契约只用于当前规划和交付资格核验；历史失败轨迹的事实审计不因缺少新路线字段而失效。
