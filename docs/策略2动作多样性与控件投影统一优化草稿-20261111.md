现状：

### 1b `_bind_target` 移入有界检查点

`screenshot_session.py:420`（`_execute_round`）

现状：`matches = self._bind_target(step)` 在 `:435-440` 的 `try/except ValueError` 之外，绑定器任何异常直接逃逸成 program 级 RAW_PENDING 终态。

改为：
```python
        try:
            matches = self._bind_target(step)
        except (KeyError, ValueError, TypeError, IndexError) as error:
            await self._checkpoint('binding', feedback={
                'kind': 'STEP_NOT_EXECUTABLE',

                'step_position': self.position})

```

复用既有 `STEP_NOT_EXECUTABLE` 词汇（`:438`）。不捕 `Exception`：避免掩盖真实缺陷与吞掉 asyncio 异常。`_react_step` 里 drag 终点的 `_bind_target` 已在既有 try 内，无需改。

### 1c failureClass 归因不一致 —— **待用户定，有行为影响**

同一次失败：`event=session_end ... failureClass=program`，`event=failed ... failureClass=collector`。

根因：`screenshot_session.py:155` 已把 `'failure_class': self.failure_class`（`:132` 对宿主异常置 `'program'`）放进 summary，但 RAW_PENDING 结算分支 `collect_runtime.py:550` 丢弃它、硬写 `'collector'`：
```python
        result=await finish_failure('interrupted' if summary['unknown'] else 'collector',
            'react_raw_ending_pending:'+ending['reason'],_evidence(pending),
```

- **1c-full（推荐）**：改为 `summary.get('failure_class') or ('interrupted' if summary['unknown'] else 'collector')`。日志与结算一致；program 级 RAW_PENDING 会触发 `collect_runtime.py:474` 的 `set_scope_paused(True)`，即宿主缺陷暂停派发而不是继续消耗候选。这是其余 program 路径（`:599`、`:618`、`:679`）已有的既定行为，RAW_PENDING 是唯一丢弃 session 自身分类的分支。
- **1c-min**：只让 session_end 日志改写为结算实际采用的类别。零行为变化，但把宿主缺陷继续记成 collector，掩盖问题。

1a+1b 落地后，绑定器缺陷不再产生 program 级 RAW_PENDING，所以 1c-full 平时不会触发；它只在真的出现新宿主缺陷时生效。

### 2c 正文子树优先于站点 chrome

新增一个共用辅助（`interaction_affordances` 也用它）：
```python
_CONTENT_ANCESTOR = re.compile(r'content|main|article|post|entry|parser-output', re.I)

def _content_subtree_ids(state):
    """Element ids inside the page's own content subtree, from the sealed state."""
    elements = {e['element_id']: e for e in state.get('elements', [])}
    inside = set()
    for eid, element in elements.items():
        node, seen = element, set()
        while node and node.get('parent_id') not in seen:
            seen.add(node.get('parent_id'))
            if node.get('native_role') in ('main', 'article') or _CONTENT_ANCESTOR.search(
                    str(node.get('id') or '') + ' ' + str(node.get('class') or '')):
                inside.add(eid)
                break
            node = elements.get(node.get('parent_id'))
    return inside
```

```python
def _control_tier(control, allowed, content_ids=()):
```

### 3a SYSTEM_PROMPT 补全动作空间

`screenshot_plan.py:42-53`。**保留 SSD 线新增的全部句子**（type 插入语义、自主目标只改不匹配字段、五步即可 complete），在其后追加：

### 3b 优先使用可点控件 + 禁止纯线性阅读目标

同处追加：

> 规划优先用页面已提供的可点控件组织路径：目录与章节链接、正文内链接、标签页、展开折叠、搜索与筛选控件。能通过点击、输入或选择达成的推进不要退化为连续滚动；同一动作连续重复只在确实推进阅读且当前帧没有更合适的可点控件时才允许。自主目标不得是"通读全文""浏览到页面末尾"这类纯线性阅读：必须落到需要核实的具体事实，并包含至少一个非滚动交互。

### 3c (b′) 交互形态清单作为事实下发

```python
def interaction_affordances(observation, limit=12):
    """Factual inventory of what this frame lets a plan interact with.

    Derived only from the sealed state. An absent category means the frame
    really offers nothing of that kind, so the caller must not demand it.
    """
    state = load_json(observation['evidence']['state']['path'])
    content_ids = _content_subtree_ids(state)
    kinds, rows = [], {'in_page_links': [], 'content_links': [], 'inputs': [], 'toggles': []}
    for cid, control in (observation.get('controls') or {}).items():
        element = control.get('element') or {}
        binding = control.get('binding') or {}
        if element.get('visible') is not True:
            continue
        text = (element.get('text') or '').strip()[:40]
        href = str(binding.get('href') or '')
        tag = binding.get('tag')
        if _AUTH_TEXT.search(text) or _AUTH_SELECTOR.search(str(binding.get('selector') or '')):
            continue
        if tag in ('input', 'textarea', 'select') or element.get('inputable'):
            rows['inputs'].append({'control': cid, 'tag': tag, 'label': text})
        elif element.get('native_role') == 'tab' or element.get('aria_expanded') is not None \
                or (tag == 'button' and element.get('clickable') is True):
            rows['toggles'].append({'control': cid, 'label': text})
        elif tag == 'a' and href.startswith('#'):
            rows['in_page_links'].append({'control': cid, 'label': text, 'href': href[:80]})
        elif tag == 'a' and href and cid in content_ids:
            rows['content_links'].append({'control': cid, 'label': text, 'href': href[:120]})
    for key in ('in_page_links', 'content_links', 'inputs', 'toggles'):
        if rows[key]:
            kinds.append(key)
            rows[key] = rows[key][:limit]
    return {'kinds': kinds, **{key: rows[key] for key in kinds}}
```
月食首帧预期：`in_page_links` = 目录 9 节（序言/月食类型/没有月环食/月食过程/时间/月食与科学研究/参考文献/外部链接/参见），`content_links` = 大气折射/月球/2019年1月21日的月全食…，`inputs` = 搜索维基百科，`toggles` = 隐藏目录/隐藏外观/搜索/关闭 → `kinds` 4 类。Muxtly 计算页预期：`inputs`（长/宽/厚/数量）+ `toggles`（计算）→ 2 类，无需任何链接即满足。
