# 生产者证据目录用途说明

文档日期：2026-11-18。目录及容量统计来自本会话 2026-11-17 的只读检查，不代表当前实时数量。

`database/sqllite/prod/producer-evidence/` 是正式生产工程中，生产者发现和筛选候选网页时保存原始材料、观察事实、选页决策和批次报告的持久证据目录。它用于回答“页面从哪里发现、当时看到了什么、为什么被选入或拒绝”，不等于消费者已经完成采集的成功样本，也不应作为普通临时缓存整体清空。

## 在采集链路中的作用

生产者发现入口并访问网页后，将页面原件和观察结果保存到本目录；选页时形成决策材料，再把候选及其证据引用写入数据库。后续来源核验、历史结果复用和批次续接会读取这些文件。

数据库承担结构化记录、账本和文件引用；本目录承担引用对应的文件原件。保留数据库而删除其引用文件，会留下记录但失去相应来源证明。

默认批次目录由 `current_evidence_roots(chain)[0] / 'producer-evidence' / object_sha256(run)` 生成。长摘要目录名对应批次身份，并非一个目录对应一个成功样本。站点首页准备流程也使用这个证据根。

## 文件内容

| 文件类型 | 保存内容与用途 |
| --- | --- |
| `site-home-*.json`、`site-home-*.html` | 首页原件、正文、中文链接、HTTP 状态等，支持站点分类和入口发现 |
| `response-*.bin`、HTML 文件 | 网页原始响应及渲染后的页面内容 |
| `viewport*.png`、`frame-*` | 生产者访问页面时的截图、分帧观察等证据 |
| `document.json` | 请求地址、落地地址、标题、正文、编码、HTTP 状态，以及原始 HTML 和渲染 DOM 引用 |
| `observation.json` | 页面文字、链接、控件、跳转、导航错误、截图引用等观察事实 |
| `entry-links-*.json` | 选页决策、调用记录、页面处理记录、拒绝原因等；不同历史协议字段存在差异 |
| `grounded-report-*.json` | 批次候选 ID、产出、模型用量、停止原因、未完成范围等汇总 |

这些材料覆盖生产者筛选过程，可能包含未入选页面及失败记录，不能用文件数或目录数推算有效业务页数、成功采集数或验收数量。

## 删除和清理的影响

证据引用携带路径和 SHA256。现有核验逻辑要求引用文件存在，并验证内容摘要；删除被引用文件或直接改写内容，会使相应证据核验失败，影响候选来源读取、历史复用或续接。

因此，不能仅按“批次已结束”“未产生成功样本”“文件较旧”判定可删除。若后续需要清理，应先核对数据库记录、checkpoint、报告及文件之间的引用关系，区分仍被引用的原件与确无引用的文件，再形成具体清理清单。

本次仅检查目录结构、文件类型及容量，抽样读取 JSON 字段，并核对相关实现；没有逐项完成全部数据库及递归文件引用核查，**尚未确定安全可清理的文件或容量**。没有修改产品代码、数据库或证据原件，也没有启动生产者、消费者或真实模型请求。
