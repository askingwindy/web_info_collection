# 消费者50候选实施与冻结验收

本轮用户授权范围为固定50个Table2候选，包含12个定向与38个分层候选，不是50个成功。不补第51个，不另选真实试跑。名单及逐行来源由主会话冻结在 `verify_results/consumer-agent-fifty-parent-20261103-r01/cohort-50.json`。原工程scope、manifest、候选池、注册库、模型账和各行原生产批均复用。独立QC及全批分析由主会话执行，本实施会话不发起QC、人工审核或发布。

## 工程代码

`browser.stability_pair` 新增 `webcollect-related-stability-6`。同帧原框与复核框最大边偏移允许不超过5 CSS px（含5），每次使用记录元素身份、原框/复核框、实测偏移、DPR、图像坐标换算及真实命中证据。当前截图明确采用 `scale=css`，交付图像坐标缩放为1，物理像素位移另外按实测DPR记录。语义状态、目标身份、命中、遮挡、保护区与结果仍须一致。

几何规则与图像规则分开：相同PNG的坐标微移不扩大像素范围；实际旁侧元素平移必须证实移动图块逐像素一致、移入/露出区域为同一背景色，变化限于移动前后框的并集，且与目标、结果、文字及其他交互控件分离。保护区或文字变化不归噪声；证据不足重新观察或拒绝。截图、原始树和复核树完整保留，v1–v5收据继续按原版本复算，历史失败不回签。未加载图片只有明确装饰性、非交互、与文字/目标/结果/保护区无关且证明完整时才允许继续，仍不豁免其像素。汉典缺失字形图保持未决，仅离线回放，不补点击。

新任务冻结 `webcollect-explicit-href-landing-1`。同一标签页，原点击明确href与后续落地URL严格相符，期间无其他浏览器动作、没有新标签页，才能引用后续真实观察。原动作、后续观察和绑定分别保留，不新增动作或改写旧后帧。后加工重算连续性及末帧绑定。无关自动跳转、其他动作、新标签等均拒绝。

正式消费者的 `--cohort` 兼容 `webcollect-consumer-multibatch-cohort-1`，按每行原发布批及原子领取摘要领取。不修改池/manifest绑定，不换号补位，旧单批cohort保持原意。

## 规划采集Agent

Goal保留冻结requested_goal和当前观察支持的working_goal。单执行者、observe/inspect/act/finish四工具及单会话最多25次真实GLM HTTP保持。首轮提示使用原目标、站点主类、有据页面用途与可信首帧，给类型意向、依据及可见结束条件，再选本轮一个工具；用途UNKNOWN可先观察。集合短流程和近重复比例只有各自有证明才提供，未知保持UNKNOWN。分类仅选题线索，目录链接不等于已访正文，自然短流程允许且不凑步。

宿主冻结 `webcollect-planning-intent-1` 并保存模型意向和依据；模型看到task_intent、planning_basis、实际效果反馈及原观察引用。inspect search按普通可见文字检索，精确标签优先，可指定exact/contains和role；零命中给纠正用法。检索结果不提升动作资格。

后加工从真实控件、动作、前后状态和末帧分别派生内部交互类别与1–3个客户枚举，保存逐项依据；意向不作为实际标签。查询提交须有变化后的可见结果，筛选排序须有实际控件及结果变化，设置须有状态变化；计算填写和可见结果、定向文档/规则/书摘阅读分别记录。未发生的购买、对局不声明；无对应枚举的实际交互保留类别、依据和待判状态。

## 冻结后的只读发现

本轮固定源码启动后发现一个分类边界：`target.owner.state` 的仅聚焦变化不足以证明修改设置。当前checkout已排除此情形并通过新增负例的9项定向检查。正在运行的50候选仍使用原冻结副本；后继离线修正不能算作本轮实跑版本。原始标签、动作及收据保留，实际暴露范围由原记录单列核对，见本轮证据目录的 `postfreeze-findings.json`。
