# 消费者第二轮：只读选样、阅读与差异审核

本轮在原工程与共享工作区实现、离线测试和原件只读回放。原生产、请求、claim、尝试、保存和审核均不重置。本工程改动不授权真实请求、采集或 QC；真实第二轮与独立审核由主会话执行，离线结果不计产量。

## 工程入口与门禁

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=projects/code:projects/site-planner:projects/quality-inspector \
projects/code/.venv/bin/python -B -m webcollect.candidate_cohort \
 --scope results/candidate-project-20261101-r01/scope.json \
 --output verify_results/consumer-fifty-round2-selection-20261103-r01 \
 --count 50 --seed consumer-fifty-round2-20261103
```

输出目录必须全新。`--dry-run` 仅生成 audit.json、rows.json；`--candidate-list <JSON原candidate_id数组>` 按原顺序核对，任何拒绝都保留缺额，不能换候选补名单。自动选择按类目、应用轮转及稳定 seed 摘要排序。仅完整名单生成 `cohort.json`，直接交原 `candidate_consumer --pool … run --cohort … --protocol entry`。冻结本身没有领取或派发动作。

筛选从原 Table2 NEW 发布行开始，逐层核对 pending、无处置、从未 claim、当前版本及原版本正文、去重身份、所有来源收据、原 GET 2xx 与其原 job/唯一已结算 visit。然后运行与真实 worker 相同的 `guard_candidate_dispatch(uri, candidate_id=原ID)`，包含模型请求、站点事实及正式规划未决作业。每层分母、逐行拒绝原因分别留在 audit/rows；页面用途 UNKNOWN 不自行降为不可用。

冻结保留原发布批、发布行、响应摘要、版本、body 与 sources 摘要、GET 引用及 scope/manifest/config。worker 独占领取事务再核对冻结正文/来源/GET，已有历史 claim 则跳过原行，不补位。新产生的门禁变化仍由原 worker 在派发时拒绝；只读通过不能保证未来可派发或浏览器可用。

## 规划采集 Agent 的 goal、prompt 与 tool

Goal 保留 requested_goal 与当前有观察依据的 working_goal；不把来源类别、第五步或模型摘要当作目标完成。

Prompt 增加 `reading_progress`：当前滚动位置、新显示正文、已显示正文、原观察与历史位置。已显示只意味着曾进入同步树，不等于读懂或已完成任务。回看须说明原观察的具体待核字段与用途；已核对完就结束，不为长度回到旧区域。

工具仍为 observe/inspect/act/finish。工具宿主用原动作及同步前后状态计有效操作；finish/complete、wait 和查询单列。当前暂定：5 个真实有效操作且目标可见结果已达到就立即 finish；自然短流程继续单列。第五步不自动成功；宿主只证明计步与可见材料，业务完成不由计数推断。无可见末帧不能放行。

新任务冻结 `webcollect-reading-progress-1` 和 `webcollect-five-effective-visible-ending-1`。真正两步原样往返保持拒收，原动作不删去后拼接。有据返回仅在后续真实操作使用原先可见、滚动后不可见、返回后再次可见的同一有标签控件时由原状态核验；纯“回看”文字不能豁免。原导航 back 的有据另一分支许可保持。旧任务缺扩展时按旧轨迹规则解释。

## 保存、导出与独立审核

新生成的任务叙述把引号外书名号改成「」，引号内原句和原始 goal/PNG/树/请求保持原样，避免保存后首次客户导出才暴露标点错误。保存数量、客户格式导出与 QC 交接分别写 `delivery-stages-<摘要>.json`；导出或交接拒绝保留具体阶段与原原因，不否定或伪造已有正式保存，不启动 AI 审核。

独立差异作业仍走 `ai-difference` 正常队列，新作业冻结 `image-difference-bound-pairs-1`。每次模型比较只带当前焦点与一个邻居及该对待核事项；原整组清单保留在作业证据中，由宿主汇总 required/covered/missing 历史 ID。分段仅可引用本次展示的焦点帧；整体汇总保留各段失败或未决，不得将 UNKNOWN 重发或用新作业改为 PASS。

逐帧材料明确：第 i 张图是第 i 动作的前帧，第 i+1 张是其结果；末尾 complete/finish 自带既有末帧，没有额外后图，逐动作图像差异对其为不适用。必要非末端结果图缺失、缺少历史对照或显式比较集合为空均不能预填差异 PASS。整条样本和短流程计步仍按全轨迹判断，不对子分段额外要求五步。

仅更新 `semantic.RULE_VERSIONS['substantive_difference']` 为 `actual-trajectories-bound-pair-coverage-and-terminal-images-3`。原四项 AI 规则版本保持；新差异协议进入语义复用身份。旧审核原件不改写，受影响差异项按规则绑定待复核。`qc_layers` 另报全帧 AI 回执数、五项全裁决数及原样本状态；AI、格式、包级资料、集合分布、人工、发布和客户验收独立。
