# 消费者 V8 原件派发与剩余计划修复

本次是消费者工程与规划 Agent 的定向离线修复。新增冻结协议 `webcollect-banded-conditional-plan-8`，V1–V7 及历史原请求、失败、UNKNOWN 不改签。没有访问线上网页、发起真实模型请求、运行生产 runner 或启动 QC。

## 工程代码

R07 首轮指定的已核实搜索框未进入 6,500 字符投影，模型原引用因此被作用域校验拒绝。V8 将该首步焦点优先放入同一投影预算；可引用节点仍只来自本次请求，过期 ID、不同文档、未知节点均拒绝。实际页面保留在当前浏览器会话，首轮仍只提交一次完整 `submit_plan`。

V8 对当前请求的唯一可见节点和精确标签接受附加位置/父文案提示。角色、href、明确左右栏、同名歧义、广告祖先及动作资格仍须验证。缺命中探针的节点只能先走原定向观察，不能因此直接取得实际动作资格。未来页面仍使用语义，不沿用旧节点。

R07 长档七步后只剩计算按钮的一步，原重规划把剩余段写成 short，已有理由在 band_reason；宿主按新短流程拒绝。V8 重规划继承原档、目标和八步总额度，可以只交 `steps`，不能通过重规划重置额度或换档；原始回包与宿主规范化计划分别留证。

显式会话目标的 minimum_effective_steps 必须为整数，five 只接受 5，long 接受 5–8。固定输入原件不改写，本轮真实复验应从原件派生 minimum=6 的新目标文件，保持候选、URL、原 requested_goal 和任务描述。目标事实、实际步数、正式保存、独立 QC 继续分别验收。

## Agent goal、prompt 与 tool

Goal 使用原任务及其参数，首轮自行生成整段条件路径。计算如需按钮触发，须真实点击后读取具名新值；阅读必须由真实站内检索、结果落地及后续正文组成。未来正文只描述待核关系，不填答案或未见原文。

V8 的 checks 接受只有 field、可选 purpose 的待核事项。缺 page/region/visible_text 的项在事实汇总中为 PENDING；不能因模型描述、预测数值或 finish 成功成为 VERIFIED。原 goal_evidence 仍单独核实真实输入修改、结果变化与单位，或搜索来源、正文及模型选择的原文。

已选引文且少于显式最低步数时，只能继续已规划、与当前阅读有关的真实滚动；没有这样的剩余路径则照实提前结束并报告不足。同一已打开文档上的引文，在后续实际有效滚动后保留原观察来源，不能冒充末帧文字。跨文档、无位移或其他动作不能凭这项规则保留引文。

有页面证据的网站快捷键可以聚焦真实搜索框。页内查找只按真实效果记账，不替代站内搜索或用户要求的真实滚动。wait、观察、取证和 finish 不计有效业务动作。

首轮真实工具定义为 `tools(grounded=True, pending_checks=True)`；分支响应定义为 `choice_schema(grounded=True, inherited=True)`。首轮与宿主使用同一动作 schema，分支仅发送当前动作/参数摘要和响应 schema，不在消息正文重复大份 schema。实际系统提示由 `system_for(task)` 生成。新增参数有默认值，旧任务继续采用原定义。
