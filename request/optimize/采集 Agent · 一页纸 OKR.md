# 采集 Agent · 一页纸 OKR

> 目标:20w 条网页数据轨迹 | 现状单页 10min | 周期: ASAP

---

### 目标(Objective)
做一个采集 Agent:输入 URL → 自动规划操作路径 → 截图采集,产出 20w 条轨迹,且分类占比合规。

### 现状与核心问题(Key Results 背景)
- **慢**:每页完整 ReAct 规划 ~10min → 20w 串行 ≈ **3.8 年**,20 路并发仍 ≈ 70 天。
- **弱**:新站从 0 探索 → 规划失败率高。
- **险**:naive 挖掘 → 撞 ≤20% 配额顶,比例违约。
- **根因**:规划与执行耦合,成果用完即弃,无沉淀。

### 方案一句话
**模板化复用 + 规划/执行解耦**:把"每页 10min 的 ReAct"压成"每模板一次、同结构页秒级复用"的沉淀飞轮,先验证复用率再扩规模。

### 关键指标(KR)

| KR | 目标 |
|---|---|
| 模板命中率 / 平均复用率 | ≥80%(吞吐命门) |
| 分类占比 | 每类 ≤20%(合规命门) |
| 单位轨迹成本 | 元/有效轨迹可控 |
| 失败页有产物率 | 100%(降级兜底) |
| 全量周期 | 一周内 20w |

### 里程碑(Milestones)

| 阶段 | 内容 | 周期 | 闸门 |
|---|---|---|---|
| **Phase 0** | 复用率 PoC:100 页同站测"模板数+复用率" | 1-3 天 | 复用率 ≥80% 才继续 |
| **Phase 1** | 最小消费者内核:Matcher+Planner+Executor+TemplateStore | 1-2 周 | 命中率 ≥80%、复用页秒级 |
| **Phase 2** | 生产者配额调度 + 质量过滤 + 指纹预产 | 1 周 | 分类 ≤20% 不违约 |
| **Phase 3** | 双队列并发 + 工具站 SafetyHook + 20w 全量 | 跑顺后 | 一周内 20w |

### 硬约束
**Phase 0 不达标,不进 Phase 1;命中率不达标,不上并发。** 先证可行,再扩规模。

### 风险 Top1
复用率不达标 → 调 fingerprint 粒度再测;仍不达标 → 评估分层规划。**这是唯一能让 20w 工期崩盘的风险,Phase 0 提前暴露。**

### 下一步
立即启动 Phase 0,出两个数。
